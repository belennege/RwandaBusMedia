# Rwanda Bus Media Control System

A centrally controlled audio advertising system for buses.

## Project Goal

Control advertising audio on multiple buses from a central web dashboard.

## Main Architecture

Laptop
→ Cloud Server
→ Bus Player
→ Bus Radio
→ Speakers

## Development Stages

1. Local audio player
2. Raspberry Pi player
3. Remote control
4. Cloud + MQTT
5. Web dashboard
6. Database
7. Advertisement management
8. Scheduling
9. Monitoring
10. Multi-bus deployment
